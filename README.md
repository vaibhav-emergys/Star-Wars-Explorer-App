# Star Wars Explorer 🚀

A modern and interactive React app that allows you to explore characters, planets, vehicles, films, and more from the Star Wars universe. Built with **Vite**, **React**, **Tailwind CSS**, and live data from the [SWAPI Reborn](https://swapi.info/).

---

## 🔥 Features

- 🔍 **Search Across Resources**

  - Perform real-time searches across people, films, planets, starships, species, and vehicles.

- 📦 **Clean Pagination**

  - Elegant pagination UI with icon-based navigation and page tracking.

- 🧠 **Global Caching with Context API**

  - Fetched data is globally cached to reduce redundant API calls and enable faster modal navigation.

- ✨ **Expandable Resource Cards**

  - Clickable cards that expand into modals showing full details with navigable sub-resources.

- 🖼️ **Nested Modal Navigation**

  - Navigate between related resources (e.g., people → film → starship) without leaving the modal.

- 💡 **Debounced Search Input**
  - Responsive and optimized search experience with debounce functionality.

---

## 🛠️ Tech Stack

- ⚛️ **React** – Component-based UI
- ⚡ **Vite** – Fast bundling and dev environment
- 💨 **Tailwind CSS** – Utility-first styling
- 🌐 **SWAPI Reborn** – Star Wars REST API
- 🧠 **Context API** – App-wide state and data caching
- 🗂️ **React Router DOM** – Navigation and routing (if used)
- 🔁 **Custom Hooks** – For data fetching and debounce
