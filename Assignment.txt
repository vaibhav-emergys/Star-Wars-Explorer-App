## Assignment: **Star Wars Explorer App**

**Objective**: Build a React app in **one week** that lets users explore Star Wars characters using the **SWAPI Reborn** API (`https://swapi.info/api/people`).

### Required Features

* **Fetch Paginated Data**

  * Load characters from `https://swapi.info/api/people`
  * Allow navigation through pages (e.g., “Next” / “Previous”)

* **Search by Name**

  * Add client-side search on character names
  * Debounce input to avoid rapid re-renders

* **View Details**

  * Clicking a character displays more info (modal or dedicated page)

* **Loading & Error Handling**

  * Show loading indicator during fetches
  * Display friendly error messages on failure

* **React Best Practices**

  * Use `useState`, `useEffect`, and optionally `useContext` for theme or state management

* **Bonus (optional)**

  * Infinite scrolling instead of pagination
  * Theme switching (light/dark) via Context API
  * One simple test (e.g., loading state or search filter behavior)
